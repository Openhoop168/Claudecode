Claudecode

Claude GitHub 工作流操作顺序清单：用 Issues 派活，让 Claude 自动完成开发闭环。

Issues→ @claude→ Pull Request→ Actions→ Merge

1. 提需求

在仓库 Issues 里新建 issue，写清任务和验收标准，并 @claude。

2. 触发执行

在 issue 下评论 @claude 请开始执行，Claude 会自动创建分支和 PR。

3. 审查与合并

看 PR 的 diff 和自评审，满意后 Merge，再到 Actions 确认工作流通过，本地 git pull 同步。
